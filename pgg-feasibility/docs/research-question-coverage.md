# Coverage of the research questions

The 60-block announcement experiment is finished. It compares a recording-only
monitor with an additional language-triggered enforcement route in rounds
1 to 3, before punishment is available. LIVE adds both an enforcement route
and a connection to the group's own messages, which remain competing
explanations of the opening effect. The earlier full-game pilot remains a separate
6-block comparison. Neither is a matched test of the rule-learning questions
below.

| Question                                                     | Existing evidence                                                                                                                                                                                                                                    | What is still missing                                                                                                                                             |
| ------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- | ----------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| How do agents learn an opaque enforcement mechanism?         | Four full/coarse language-policy disclosure games explored knowledge of the scorer and its threshold. The public contribution penalty and history trigger remained known. A separate hidden-threshold proposal was shelved before native collection. | A controlled test of learning an unknown execution rule, with the information set, feedback, learning target and stability criterion defined in advance.          |
| Does communication accelerate that learning or exploitation? | Early Qwen chat/no-chat games and later public/private-preparation diagnostics exist. The former had no punishment institution; the latter included numeric reports and did not randomize rule opacity.                                              | A matched opacity-by-communication comparison with a predefined learning-speed outcome. All arms of the fresh twelve-game H/H+L comparison allowed communication. |
| How do agent results compare with human behavior?            | A separate Morgan-data measurement benchmark covers 110 archived five-round games across six sessions. A session-held-out forecast audit uses the original human-coded pregame requests.                                                             | A human-agent comparison under matched rules, endowment, horizon and message timing. The current human and agent observations are not matched controls.           |

The shelved opacity argument concerned a specific information claim: under the
known original sanction family and a common scalar threshold, one player's total
deduction induces the same candidate-threshold partition as all four deductions.
This rules out that proposed private-deduction aggregation advantage. It neither
tests nor rules out language-assisted exploration or learning an unknown
execution mechanism. The proposed implementation also bundled several kinds of
disclosure, preventing a clean threshold-opacity interpretation.

The four-game disclosure result is exploratory (two games per condition).
Changing the disclosed policy package does not by itself identify learning
speed. The zero-risk or cooperative behavior in other protocols is not evidence
that communication cannot accelerate adaptation in an opaque institution.

The current proposed own-message versus paired-group-message comparison
addresses the source of an additional enforcement warning. It is unexecuted
and is not a substitute for the missing opacity-by-communication comparison.
